
## 0.16.2 (2026-11-23)


### Bug Fixes

* **combat:** debuffs should always reduce stats by at least 1
* **controller:** controller-driven combats, often from a few feet away, should now be easier to see what's going on targetting-wise
* **controller:** don't show controller prompts on home page
* **controller:** edicts should be row-selectable in controller mode
* **controller:** recenter will actually recenter on locations that are slightly near map boundaries
* **controller:** task menu has better controller support
* **core:** soft/hard cap goes from 1/4 to 1/2 w/ a 50% xp dropoff
* **edict:** edict of spontaneous memory will now drop items in the appropriate zones
* **edict:** under the spontaneous memory edict, drops that are not possible to get from locations will not be shown


### Features

* **combat:** don't show extraneous info in combat log
* **controller:** better support for navigating world panels with a controller
* **controller:** better, granular support for toggling between ui zones with l3
* **controller:** support confirming skill tree with r3
* **controller:** support inspect in combat for controller players
* **controller:** support optimize all having a hotkey
* **controller:** support range select in armory with controllers
* **controller:** support row selection for astral projector
* **whisper:** allow founder whispers into combat logs if they're directly related to combat
* **world:** add pity drops for rewards on locations
