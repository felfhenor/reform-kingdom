# Content Segments

To keep content separated in ways that makes sense, content should touch different areas of the game to improve it separately. Improvements are sorted into the following categories:

- Duchy Upgrades
- Economy
- Hero Stats
- Hero Exploration
- Hero Skills
- Combat Stats

Content comes from a few different categories that can call on these improvements:

- Affixes
- Astral Projector
- Collectibles
- Equipment
- Infusions
- Shrines
- Town Buffs
- Trainers

## Duchy Upgrades

Duchy upgrades are broadly categorized as "things that increase the capabilities of the Duchy". This would include things like armory-size-increasing effects, tradeskill queue boosts, etc.

## Economy

Economy controls things that are global boosts. This includes XP gain boosts, gold gain boosts, etc.

## Hero Stats

Hero stats include strictly only anything that increases the numerical value of hero stats (STR, AGI, etc).

## Hero Exploration

Hero exploration includes anything that might boost exploration gains. This would include things like tradeskill yield boosts, travel speed boosts, etc.

## Hero Skills

Hero skills are anything pertaining to hero skills. This would include gaining skills or modifying skills.

## Combat Stats

Combat stats includes anything that is not a pure stat, that is to say, things like skill repeat chance, monster type slayers, debuff resistances, etc.
